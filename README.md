 FixNear 🔧

 Location-Based Appliance Repair Service Platform

FixNear is a frontend prototype for a location-based appliance repair platform that connects customers with nearby appliance technicians.

The platform is designed around a simple service journey:

Search → Find Technician → Request → Accept → Track → Repair → Payment → Rating

---

🚀 Project Overview

Finding a reliable appliance technician can be difficult, especially when a customer needs urgent repairs.

FixNear is designed to make the process easier by allowing customers to:

- Search for appliance repair services
- Enter their location
- Find nearby technicians
- View technician profiles
- Compare ratings and experience
- Request a technician
- Track the repair process
- View technician arrival status
- Complete the repair process
- Prepare for payment
- Rate the technician

---

✨ Features

 📍 Location-Based Search
Customers can enter their location and search for available technicians nearby.

 🔧 Appliance Selection
The platform currently supports:

- Refrigerators
- Washing Machines
- Microwaves
- Air Conditioners
- Fans
- Gas Cookers

 🗺️ Technician Map
A visual map interface displays the customer's location and nearby technicians.

 👨‍🔧 Technician Profiles
Customers can view:

- Technician name
- Verification status
- Rating
- Number of completed repairs
- Years of experience
- Success rate
- Supported appliance categories

 📲 Service Request
Customers can select a technician and send a repair request.

 🚗 Service Status
The prototype demonstrates the repair journey through different stages:

1. Request sent
2. Technician accepts
3. Technician en route
4. Technician arrives
5. Repair begins
6. Repair completed
7. Payment
8. Customer rating

 ⭐ Ratings
The platform is designed to allow customers to rate technicians after a completed repair.
